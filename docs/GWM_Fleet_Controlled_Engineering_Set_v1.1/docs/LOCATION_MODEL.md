# LOCATION MODEL

## Principle
No GPS dependency in MVP.

## Vehicle locations
Fleet Manager maintains known parking/operational locations.

Examples:
- Portaria P1
- Assembly Shop External Area
- Restaurant Chargers
- Paint Shop
- Administration
- Other approved locations

## Vehicle fields
homeLocationId
currentLocationId

## Final check-in
currentLocationId is mandatory.

## UX
Next user must see current vehicle location before pickup.
