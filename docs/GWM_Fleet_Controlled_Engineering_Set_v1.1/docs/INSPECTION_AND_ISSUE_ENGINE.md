# INSPECTION AND ISSUE ENGINE

## Driver and Security
Driver and Security create separate inspection records.

## Checklist items
- exterior condition
- windows
- lights
- tires/wheels
- external cleanliness
- internal cleanliness
- jack
- wheel wrench
- warning triangle
- mileage
- fuel
- battery where applicable
- parking location on final check-in

## Photo policy
No mandatory photos in normal operation.

When external damage is identified:
1. select vehicle area
2. classify severity/type
3. describe damage
4. capture at least one photo
5. optional framing guide may be shown
6. issue cannot be completed without evidence

## Issue outcome
Issue can:
- be informational
- create operational task
- block vehicle
- trigger notification
