### Core transitions
AVAILABLE -> RESERVED
RESERVED -> AWAITING_PICKUP
AWAITING_PICKUP -> IN_USE
IN_USE -> INSPECTION
INSPECTION -> AVAILABLE
INSPECTION -> CLEANING
INSPECTION -> CHARGING
INSPECTION -> MAINTENANCE
ANY -> BLOCKED when critical blocking condition exists

BLOCKED -> AVAILABLE only through authorized resolution workflow.
