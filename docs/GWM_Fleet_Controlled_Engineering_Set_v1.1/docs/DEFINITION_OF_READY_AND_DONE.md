# DEFINITION OF READY / DONE

## Definition of Ready
An implementation pack is ready only if it has:
- scope
- requirement IDs
- actors
- business rules
- domain entities
- state transitions
- API contract impact
- permissions
- acceptance criteria
- failure scenarios
- test scenarios
- dependencies

## Definition of Done
A feature is done only if:
- code implemented
- build/lint pass
- migrations pass
- unit tests pass
- integration tests pass
- API contract tests pass where applicable
- authorization verified
- audit verified where applicable
- error model compliant
- documentation updated
- golden scenarios pass where applicable
- QA approval recorded
