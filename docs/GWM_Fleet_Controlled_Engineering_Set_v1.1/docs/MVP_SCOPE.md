# MVP SCOPE v1.0

## In Scope
1. Authentication and role-based access
2. Driver authorization and CNH validity
3. Fleet master
4. Vehicle models, categories and powertrain types
5. Vehicle current status and location
6. Trip request
7. Availability calendar
8. Booking policy engine
9. Vehicle recommendation
10. Carpool matching
11. Approval workflow
12. Reservation lifecycle
13. Check-out / check-in
14. Security / Gate independent checklist
15. Fuel and battery level capture
16. External damage reporting with mandatory photo
17. Operational workflows
18. Vehicle blocking and release
19. Cleaning scheduling
20. Charging scheduling
21. Fueling task
22. Maintenance alerts by mileage
23. Communication Hub
24. Delay impact detection
25. Vehicle reassignment
26. Fleet Manager dashboard
27. Notifications
28. Audit trail
29. Configuration catalog
30. PT-BR as initial language with i18n-ready architecture

## Explicitly out of MVP
- OBD integration
- GPS/telemetry integration
- remote vehicle unlock
- key cabinet integration
- computer vision damage detection
- automated charger integration
- full TCO engine
- full insurance module
- full fines management
- employee rental execution
- autonomous generative AI agents
- advanced route optimization
- advanced predictive fleet sizing
