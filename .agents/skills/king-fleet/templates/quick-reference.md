# King-Fleet Quick Reference

1. Read `/docs`.
2. Create `.king-fleet/`.
3. Establish Technical Baseline.
4. Build Master Issue Registry.
5. Run specialist analysis.
6. Present proposed plan.
7. Wait for human approval.
8. Freeze Approved Baseline.
9. Decompose into tasks.
10. Build dependency graph.
11. Create isolated branches/worktrees.
12. Execute in safe parallelism.
13. Test.
14. Self-check.
15. Independent review.
16. FAIL -> repair -> fresh review.
17. PASS -> controlled integration.
18. Run regression.
19. Run full-system validation.
20. Chief Reviewer.
21. Completion Audit.
22. Only then declare COMPLETE.
